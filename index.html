MILD: A Dataset and Benchmark for Replay-Oriented Localization

MILD studies localization in close-range robot teaching, where the tracked trajectory is used as the downstream replay target rather than only as a navigation path.

Dataset

Manipulation sequences with task-level replay structure

MILD focuses on UMI-style robot teaching at tabletop scale. The real-world subset includes free-space trajectories, bookshelf retrieval, box interaction, pick-and-place tasks, and wiping tasks. Each task is recorded under controlled scene conditions such as plain table, tablecloth, AprilTag, and ArUco variants.

The dataset packages sensor streams, robot end-effector reference sidecars, gripper-event timing, and calibration assets so that localization output can be compared against a replay-relevant target trajectory.

Insta360 X5 panoramic sensing and Insight9 RGB-D sensing near the gripper.

Benchmark

Localization difficulty is shaped by task motion and scene condition

MILD compares tag-free, tag-based, and tag-assisted localization routes using APE RMSE and trajectory completion. The benchmark highlights that tabletop manipulation introduces failures not visible in standard navigation datasets: hand and object occlusion, close-range viewpoint changes, and replay-sensitive endpoint motion.

AprilVINS

Tag-assisted visual-inertial localization without a surveyed tag-map prior

AprilVINS lifts fisheye tag observations to unit-sphere rays, estimates a sequence-local tag layout, admits consistent tag-pose priors into a fixed-lag VIO optimization, and promotes only validated trajectory outputs.

This design targets manipulation teaching routes where a small number of tags can stabilize trajectory estimation without requiring a pre-surveyed global marker map.

Collection pipeline

From teleoperation to replay-aligned reference trajectories

Demonstrations are recorded with time-aligned robot states, end-effector poses, gripper events, and sensor streams. The same task trajectory is replayed under scene variants to expose how environment changes affect localization while preserving the manipulation intent.
