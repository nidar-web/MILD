# MILD

Anonymous review project page for the Manipulation-Interface Localization Dataset.

This repository currently hosts a static GitHub Pages draft. Author names,
affiliations, personal links, and non-anonymous repository links are intentionally
omitted during review.

The current page is video-first: it renders local 10 s preview clips from
rosbag-synchronized MILD videos. Insta360 X5 clips show front/back fisheye
streams, and Insight9 clips show left/right grayscale streams.
